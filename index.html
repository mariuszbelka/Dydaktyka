Krzywa van Deemtera

Model i założenia
  • Retencja: model LSS, log k = log k_w − S·φ. Parametry kw i S odnoszą się do wybranego modyfikatora; zmiana ACN/MeOH wpływa tu tylko na lepkość.
  • Migracja: prędkość pasma dx/dt = u/(1+k(φ(x,t))) całkowana numerycznie. W gradiencie skład w punkcie x w chwili t to φ(t − t_D − x/u), gdzie tD = VD/F. Ta sama procedura daje tR w obu trybach.
  • Czas martwy: V_M = ε_T·πr²L, εT = 0,65 (porowate) lub 0,50 (core-shell); t₀ = V_M/F.
  • Sprawność: zredukowane równanie van Deemtera h = A + B/ν + C·ν, ν = u·d_p/D_m, H = h·d_p, N = L/H. Porowate: A = 1,2, B = 2,0, C = 0,08; core-shell: A = 0,7, B = 1,6, C = 0,06.
  • Szerokość piku: σ_t = t₀(1 + k_e)/√N, gdzie ke to k w chwili elucji (w izokracji ke = k). Dodatkowo wariancja pozakolumnowa (σ_V/F)². Kompresja pasma w gradiencie jest pominięta, więc piki gradientowe są nieco zawyżone.
  • Pojemność pików (gradient): n_c = 1 + (t_R,ost − t_R,pierw)/(4σ̄).
  • Rozdzielczość: R_s = (t_R2 − t_R1) / (2(σ₁ + σ₂)); Nobs = (tR/σ)². Piki są gaussowskie (bez ogonowania).
  • Ciśnienie: prawo Darcy'ego ΔP = Φ·η·L·u_s/d_p², Φ = 1500, us – prędkość pozorna. Lepkość mieszanin woda–ACN i woda–MeOH w 25 °C z przybliżenia empirycznego; w gradiencie podawane jest maksimum.
  • Wartości są orientacyjne: model służy do nauki zależności (φ, F, L, dp, VD, σV), a nie do przewidywania konkretnej metody.
